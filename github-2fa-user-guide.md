# 2FA For Github User Guide 

The guide explains Two-Factor Authentication for Github Users.
> **Audience:** Everyday End-Users | **Doc Type:** Step-by-Step User Guide | **Tools:** Markdown

## Overview
2FA or Two Factor Authentication is a two way verification of services to protect it from cyberattacks. Along-with password, it adds an extra security layer like OTP or phone prompt. 

## Prerequisites
Before applying 2FA, user should have following features :
1. An active GitHub account.
2. Working GITHUB mobile app. 

## Step-by-Step Instructions
1. Log into Github account, using password.
2. On the right corner, click user-image. A dropdown appears, click on settings
3. On left side under Access section, click password and authentication.
4. Scroll down, click on a green button with - 'Enable Two Factor Authentication'.
5. A confirm access window appears, Click on 'Use Github Mobile'.
6. A verification code is being sent on mobile Github mobile app
7. In mobile, open app type the code to approve 2FA.

## Confirmation
Your GitHub account is now protected with two-factor authentication.
